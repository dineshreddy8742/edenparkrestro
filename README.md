## 🌟 Overview

**The Eden Park** is Chittoor's premier multi-cuisine highway resort restaurant and sports arena:
- **100% Strictly Separate Kitchens**: Independent preparation lines, cookware, and staff for Pure Vegetarian and Non-Vegetarian cuisines.
- **Highway Stopover Hub**: Located directly on the Bangalore–Tirupati Highway with ample car parking, EV charging, clean washrooms, and express highway traveller service.
- **Garden & AC Dining**: Open-air lawn with fairy lights, private family AC cabins, and celebration spaces.
- **Pro Turf Arena**: 7-a-side FIFA-standard turf with 300-Lux high-mast LED floodlights for box cricket and football (6:00 AM – 10:00 PM).

---

## 🚀 Key Features

- **Dedicated Page Navigation**:
  - `#/menu` — Full 45+ dish menu with dietary filters (Pure Veg / Non-Veg), category quick-jump, and 10-page printed booklet viewer.
  - `#/turf` — Interactive turf time-slot booking with live rate calculation (Day ₹600/hr, Night ₹700/hr), past-slot protection, and instant pay-at-counter or Razorpay checkout.
- **100% Mobile Responsive**: Touch-optimized interface designed specifically for highway travellers on mobile devices.
- **Local SEO & Rich Snippets**: Schema.org JSON-LD structured data for Google Restaurant, SportsActivityLocation, and FAQ rankings.

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dineshreddy8742/edenparkrestro.git
   cd edenparkrestro
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and provide your Razorpay Key ID:
   ```bash
   cp .env.example .env
   ```

4. **Start Development Server**:
   ```bash
   npm run dev
   ```

5. **Build for Production**:
   ```bash
   npm run build
   ```
